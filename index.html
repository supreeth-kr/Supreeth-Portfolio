Hirevo — AI-Powered Freelance Marketplace

A freelance services marketplace built with Python and Django, designed to streamline client-freelancer collaboration with automated project governance.

  • Features service gig listings with 3-tier pricing (Basic, Standard, Premium), client orders, and simulated escrow transactions.
  • Includes an explainable AI recommendation engine using Scikit-learn (TF-IDF vectorization) to match client project requirements with suitable freelancers.
  • Automates milestone tracking with deadline monitoring, delay detection, automated delay penalties, and administrator-managed backup freelancer assignment.
Python Django Scikit-learn Bootstrap 5 SQLite Django ORM
Mobile App & NLP
Flutter & FastAPI

SkillMatch — AI-Powered Skill & Job Matching

A cross-platform mobile application developed with Flutter and an asynchronous FastAPI backend that analyzes resumes using NLP to match job seekers with compatible job openings.

  • Parses PDF resumes with PyMuPDF to extract candidate experience, education, and technical competencies automatically.
  • Computes ATS-style compatibility scores between candidate resumes and job requirements using TF-IDF and Cosine Similarity.
  • Identifies missing keywords through skill-gap analysis, helping applicants target areas for profile improvement.
  • Integrates Supabase for cloud document storage and Firebase Authentication for secure user sign-in.
Flutter Dart Python FastAPI Supabase PostgreSQL Firebase Auth Scikit-learn
